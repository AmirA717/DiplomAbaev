# Руководство пользователя  
**Программный продукт:** «Кибер-образование»  
**Формат:** веб-приложение (frontend + backend API)  

## 1. Введение
Документ описывает порядок работы пользователя с приложением «Кибер-образование»: от входа в систему до прохождения мини-игр, викторин и работы с профилем.  

Руководство также включает действия администратора: создание и публикация тем, управление викторинами и просмотр статистики обучающихся.

## 2. Назначение и условия применения
Приложение предназначено для обучения основам кибербезопасности в интерактивном формате:
- изучение материалов по темам;
- прохождение мини-игр;
- прохождение викторин;
- отслеживание личного прогресса.

Роли пользователей:
- `Обучающийся` (`USER`) — проходит контент и видит свою статистику;
- `Администратор` (`ADMIN`) — дополнительно управляет темами, викторинами и статистикой обучающихся.

## 3. Подготовка к работе
Минимальные требования:
- `Node.js` 20+;
- `npm`;
- `PostgreSQL` (локально или через Docker);
- современный браузер (`Chrome`, `Edge`, `Firefox`).

### 3.1 Запуск backend
1. Перейти в каталог `cyber-education-backend`.
2. Создать `.env` (пример в `cyber-education-backend/README.md`).
3. Выполнить:
   - `npm install`
   - `npx prisma generate`
   - `npx prisma migrate dev`
   - `npm run prisma:seed`
   - `npm run start:dev`

По умолчанию API доступен по адресу `http://localhost:3000`.

### 3.2 Запуск frontend
1. Перейти в каталог `frontend`.
2. Установить зависимости: `npm install`.
3. Создать `.env` на основе `.env.example`:
   - `VITE_API_URL=http://localhost:3000`
4. Запустить приложение: `npm run dev`.

### 3.3 Тестовые учетные данные
После выполнения `seed` доступен администратор:
- `email`: `admin@cyber.local`
- `password`: `Admin12345!`

### 4.2 Операция 1. Авторизация
Условия:
- пользователь зарегистрирован.

Основные действия:
1. Открыть страницу входа `/login`.
2. Ввести `Электронная почта` и `Пароль`.
3. Нажать `Войти`.

Результат:
- успешный переход на главную страницу `/`.

Рисунки:
- **Рисунок 1 — Форма входа.**  
  Страница: `/login`.  
  Что сделать на странице: заполнить поля e-mail и пароль перед нажатием `Войти`.
- **Рисунок 2 — Успешная авторизация (главная страница).**  
  Страница: `/`.  
  Что сделать на странице: показать верхнее меню и блоки `Темы`, `Мини-игры`, `Викторины`.

### 4.3 Операция 2. Регистрация
Условия:
- пользователь не авторизован.

Основные действия:
1. Открыть `/register`.
2. Заполнить поля: `Полное имя`, `Имя пользователя` (опц.), `Электронная почта`, `Пароль`, `Подтверждение пароля`.
3. Нажать `Зарегистрироваться`.

Результат:
- учетная запись создана, выполнен вход.

Рисунки:
- **Рисунок 3 — Форма регистрации.**  
  Страница: `/register`.  
  Что сделать на странице: заполнить все обязательные поля и показать кнопку `Зарегистрироваться`.

### 4.4 Операция 3. Выбор темы и просмотр материалов
Условия:
- пользователь авторизован;
- в системе есть опубликованные темы.

Основные действия:
1. На `/` выбрать тему в блоке `Темы`.
2. Нажать `Открыть тему`.
3. На странице `/topics/{topicId}` просмотреть материалы, игры и викторины по теме.

Результат:
- пользователь получает доступ к контенту выбранной темы.

Рисунки:
- **Рисунок 4 — Выбор темы на главной.**  
  Страница: `/`.  
  Что сделать на странице: выбрать активную тему и показать карточки тем.
- **Рисунок 5 — Страница темы.**  
  Страница: `/topics/{topicId}`.  
  Что сделать на странице: показать разделы `Материалы`, `Игры по теме`, `Викторины по теме`.

### 4.5 Операция 4. Прохождение викторины
Условия:
- пользователь авторизован;
- в выбранной теме есть викторина и вопросы.

Основные действия:
1. Открыть страницу викторины кнопкой `Начать тест`.
2. На `/quiz/{quizId}/play` нажать `Старт попытки`.
3. Ответить на все вопросы.
4. Нажать `Завершить викторину`.

Результат:
- отображается итог: счет, число верных ответов, статус прохождения и пояснения.

Рисунки:
- **Рисунок 6 — Запуск попытки викторины.**  
  Страница: `/quiz/{quizId}/play`.  
  Что сделать на странице: показать кнопку `Старт попытки`.
- **Рисунок 7 — Ответы на вопросы викторины.**  
  Страница: `/quiz/{quizId}/play`.  
  Что сделать на странице: выбрать варианты ответов и подготовить отправку.
- **Рисунок 8 — Результат викторины.**  
  Страница: `/quiz/{quizId}/play`.  
  Что сделать на странице: показать блок `Результат` после завершения попытки.

### 4.6 Операция 5. Мини-игра «Найди фишинг»
Условия:
- пользователь авторизован;
- доступен сценарий игры типа `PHISHING_DETECTOR`.

Основные действия:
1. На карточке игры нажать `Играть`.
2. На `/mini-games/phishing` выбрать вариант `Фишинг` или `Безопасно`.
3. Перейти по всем сценариям.
4. На экране итога нажать `Сохранить результат` (опционально).

Результат:
- пользователь видит итоговый счет и рекомендации.

Рисунки:
- **Рисунок 9 — Сценарий в игре «Найди фишинг».**  
  Страница: `/mini-games/phishing`.  
  Что сделать на странице: показать карточку сценария и кнопки `Фишинг`/`Безопасно`.
- **Рисунок 10 — Итог мини-игры «Найди фишинг».**  
  Страница: `/mini-games/phishing` (экран завершения).  
  Что сделать на странице: показать счет и кнопку `Сохранить результат`.

### 4.7 Операция 6. Мини-игра «Создай надёжный пароль»

## 5. Аварийные ситуации
| Класс ошибки | Ошибка | Причина | Действия пользователя |
|---|---|---|---|
| Авторизация | Неверный email или пароль | Ошибка ввода | Проверить данные и повторить вход |
| Авторизация | Не удаётся подключиться к API | Backend не запущен или неверный `VITE_API_URL` | Проверить запуск backend и значение `VITE_API_URL` |
| Регистрация | Пароль короче 8 символов | Нарушение валидации | Ввести пароль длиной от 8 символов |
| Регистрация | Пароли не совпадают | Разные значения `Пароль` и `Подтверждение пароля` | Исправить подтверждение пароля |
| Темы/контент | Темы не найдены | Нет опубликованных тем | Обратиться к администратору для публикации тем |
| Викторина | Нельзя отправить результат | Не все вопросы отвечены | Ответить на все вопросы и повторить отправку |
| Мини-игра | Результат не сохранён | Игра соответствующего типа не настроена в админке | Сохранить только после настройки игр администратором |
| Админ-панель | Нет доступа к `/admin` | Пользователь не `ADMIN` | Войти под учетной записью администратора |
| Админ: тема | Ошибка в поле `Слаг` | Недопустимые символы | Использовать только `a-z`, `0-9`, `-` |

## 6. Рекомендации по освоению
1. Начать с раздела `/topics/{topicId}` и изучения материалов.
2. После изучения темы пройти викторину и мини-игры.
3. Регулярно проверять `/stats` для оценки прогресса.
4. Для администраторов: сначала подготовить темы и викторины, затем публиковать контент.
5. При ошибках API использовать `cyber-education-backend/README.md` и `http://localhost:3000/docs` (Swagger).
